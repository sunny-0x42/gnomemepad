# Gnomi Labs on Grok Bot

Grok Bot is a separate desktop app (x.ai/bot). This CLI cannot log into that app or click **Create new agent** for you.

## Install (2 minutes)

1. Open Grok Bot (signed in with the same Cursor / SuperGrok account).
2. Open a new chat with any Bot, or **New → Create new agent**.
3. Paste the full contents of `GNOMI-HQ-INSTALLER.md`. Confirm each routine card.
4. Paste `GNOMI-ENGINEERING-INSTALLER.md` in a new chat for the specialist desk.
5. Create sidebar sections named **Gnomi HQ** and **Gnomi Engineering**. Drag the group chats in.

Caps: one group chat holds 2–6 Bots. An account holds up to 50 Bots + group chats combined.
